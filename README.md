# Lightbox

Modern web application for an image search & interactive lightbox gallery powered by Google Image Search API and React 18.

Live demo / development server:
`http://localhost:3001` or `http://127.0.0.1:3001`

### Features
* **React 18 & Hooks**: Modern functional components, `useState`, `useEffect`, `useCallback`, `useRef`.
* **Interactive Image Search**: Real-time keyword search and preset topic tags (`#goal`, `#leadership`, `#direction`, `#nature`, `#technology`).
* **Accessible Lightbox Modal**: High-res view modal with backdrop blur, image index counter, keyboard navigation (`ESC` to close, `←` / `→` arrow keys to navigate).
* **Vite & Modern CSS Design System**: Dark theme, Google Fonts (Inter & Outfit), responsive grid layout, micro-animations.

### Instructions
```bash
# Option 1: Standard Vite Development Server
npm install
npm run dev

# Option 2: Production Build
npm run build
npm run preview
```
